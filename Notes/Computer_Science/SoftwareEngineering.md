# What is Software Engineering?

Software Engineering is the systematic approach to designing, developing, testing, deploying, and maintaining software applications.

It combines engineering principles with programming to build reliable, scalable, and maintainable software.

---

# Why Software Engineering?

Without Software Engineering

- Poor code quality
- Difficult maintenance
- Frequent bugs
- Slow development
- Unscalable applications

With Software Engineering

- Better code quality
- Faster development
- Team collaboration
- Easier maintenance
- Reliable software

# Software Development Models

## Waterfall Model

Linear development process.

```text
Requirement

↓

Design

↓

Development

↓

Testing

↓

Deployment
```

Advantages

- Simple
- Easy to manage

Disadvantages

- Difficult to accommodate changes
