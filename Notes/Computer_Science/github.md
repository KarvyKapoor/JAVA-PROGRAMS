# 🐙 GitHub

> Quick revision notes covering GitHub for interviews and backend development.

---

# What is GitHub?

GitHub is a cloud-based platform for hosting Git repositories.

It enables developers to collaborate, review code, manage projects, and automate software development workflows.

---

# Why GitHub?

Without GitHub

- Difficult collaboration
- No centralized repository
- No Pull Requests
- Harder code reviews

With GitHub

- Remote repositories
- Team collaboration
- Pull Requests
- Issue tracking
- CI/CD integration
- Open Source contributions

---

# Git vs GitHub

| Git | GitHub |
|------|---------|
| Version Control System | Git Hosting Platform |
| Installed locally | Cloud platform |
| Tracks code changes | Stores repositories online |
| Works offline | Requires internet for remote operations |

# Repository

A repository contains

- Source Code
- Commit History
- Branches
- Issues
- Pull Requests
- Releases
- Documentation

Repositories can be

- Public
- Private

---

# Clone Repository

Downloads a GitHub repository.

```bash
git clone https://github.com/user/repository.git
```

---

# Push Changes

Upload commits.

```bash
git push origin main
```

---

# Pull Changes

Download latest changes.

```bash
git pull origin main
```

---

# Branches

Used to develop features independently.

Example

```text
main

feature-authentication

bugfix-login

payment-api
```

---

# Pull Request (PR)

A Pull Request is a request to merge code into another branch.

Workflow

```text
Create Branch

↓

Develop Feature

↓

Commit

↓

Push

↓

Open Pull Request

↓

Code Review

↓

Merge
```

---

# Code Review

Reviewers check

- Code Quality
- Readability
- Security
- Performance
- Bugs
- Best Practices

---

# Merge

Combines one branch into another.

Methods

- Merge Commit
- Squash Merge
- Rebase Merge

---

# GitHub Best Practices

- Write clean README files.
- Make small commits.
- Use meaningful commit messages.
- Keep repositories organized.
- Use feature branches.
- Add screenshots.
- Document setup instructions.

---

# Common Mistakes

- Empty README
- Huge commits
- Poor commit messages
- Uploading secrets
- No documentation
- Disorganized repositories
